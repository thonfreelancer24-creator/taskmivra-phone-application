# TaskMivra Voice Owned ML v0.4 — TV / Competing-Speech Repair

Status: **REJECTED FOR PRODUCTION**

## What was tested

Three repair directions were executed against the same held-out TaskMivra user voice and unseen TV / loud-music challenge recordings:

1. stronger profile-discrimination loss with negative profiles;
2. speaker-preserving profile features (do not normalize each profile frame across frequency);
3. stronger synthetic speaker identities and TV-speaker-like filtering;
4. a FiLM-style separator-conditioning experiment was also tested locally and rejected because it regressed the held-out TV metric.

No locked benchmark output was used for training.
No third-party pretrained voice weights were used.
The real TV and loud-music challenge recordings remained held out from the clean-rights training corpus.

## Best measured v0.4 candidate

Held-out TV challenge:
- input SI-SDR: -0.053 dB
- output SI-SDR: +0.573 dB
- SI-SDR improvement: **+0.626 dB**
- locked minimum: **+1.000 dB**
- result: **FAIL**

Wrong-profile test on the same TV challenge:
- correct-profile SI-SDR: +0.573 dB
- wrong-profile SI-SDR: +0.665 dB
- correct-profile advantage: **-0.091 dB**
- result: **FAIL — enrolled profile is not yet controlling extraction reliably**

Held-out loud-music challenge:
- input SI-SDR: +0.031 dB
- output SI-SDR: +3.998 dB
- SI-SDR improvement: **+3.967 dB**
- result: suppression improves, but this does not override the TV/profile failures.

TV speech-detail band deltas versus clean target:
- 100–300 Hz: +0.10 dB
- 300–1000 Hz: -3.20 dB
- 1–3 kHz: -2.71 dB
- 3–8 kHz: -7.21 dB

The 3–8 kHz loss is unacceptable for consonant / speech-detail preservation.

## Engineering conclusion

The current small mask-based GRU separator can suppress loud music but does not yet provide reliable target-speaker selection on unseen television / competing speech. More training epochs on the same pseudo-speaker corpus are not justified.

The next production-quality training round must use a larger set of genuinely distinct, rights-cleared human speakers (public-domain / CC0 / explicit commercial-training rights) and retain the v0.4 speaker-preserving profile features plus direct profile-contrast loss.

Do not ship any v0.4 checkpoint represented by this report.
